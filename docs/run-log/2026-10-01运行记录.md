## 三、今日遇到的问题与解决（规则15：即时沉淀）

### 问题23：商品弹窗「商品编号」输入框坐标随视口变化（本次核心障碍）
- **现象**：按 09-30 已验证坐标（x=714,y=134）填编号失败——今日浏览器视口为 1800×931（昨日 1280×960），弹窗输入框整体右移：商品名称框 x=1049、商品编号框 **x=1354**（y=134 同排）。误点「查询」后列出全部商品（8+ 个 ID，无目标商品）。
- **根因**：商品弹窗输入框绝对坐标依赖视口宽度，云端浏览器窗口尺寸不稳定，**坐标不可硬编码**。
- **解决**：打开弹窗后先截图（Read）确认布局 + 枚举弹窗内 input（y≈134 一排两个 w=185 输入框，前者商品名称、后者商品编号），按位置第二输入框填写编号；查询后回读验证列表**只剩**目标 ID 3615901691003676804。
- **防再犯**：SKILL 问题记录 #23；流程固定为「截图→枚举 input→按 y 同排第二框填写→查询→回读验证唯一 ID」。

### 问题24：腾讯文档名称框 ref 每次导航后变化
- **现象**：回填 r428 时按「名称框 value 含 A1」匹配 ref 失败（页面显示值为 E429），click 空 ref 报 BU_REF_SHAPE。
- **根因**：名称框显示值 = 当前选中格（导航后为上次跳转残留 E429），不是固定 A1。
- **解决**：重新 snapshot 枚举 input，取 `input "X" [type=text edit]` 中 value ≠ 文档标题（未发布视频登记表）的输入框为名称框（d6:e139），再执行跳转。
- **防再犯**：SKILL 问题记录 #24；每次回填前重新 snapshot 定位名称框，不依赖旧 ref/旧值。
