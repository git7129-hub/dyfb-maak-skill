## 三、今日遇到的问题与解决（规则15：阻塞问题即时沉淀）

### 问题17：商品编号输入框定位错误（查询无效）
- **现象**：商品弹窗中把编号输入到了「商品名称」框（x=409,y=134，宽185）而非「商品编号」框（x=714,y=134，宽185），查询无结果。
- **根因**：两个输入框同排同 y，按「商品编号」label 找 input 的 JS 匹配失败，误选第一个宽输入框。
- **解决**：精确定位 `x=714,y=134` 的输入框（「商品编号」label 右侧，宽185）写入编号；查询按钮用 JS `button[type=submit]`「查询」click()。
- **防再犯**：输入前用 getBoundingClientRect 校验输入框 x 坐标（商品名称≈409、商品编号≈714）；查询后必须回读验证列表是否只剩目标 ID（`ID:36159...` 唯一）。

### 问题18：bu.click_xy 坐标换算错误（点错按钮）
- **现象**：把 JS 像素坐标（查询@338,227）直接当 click_xy 归一化坐标使用，点击落在错误位置（重置按钮附近），查询未触发。
- **根因**：`bu.click_xy` 使用 0-1000 归一化坐标，而 getBoundingClientRect 返回像素坐标；两者需换算 `归一化 = 像素 / 视口宽高 × 1000`。
- **解决**：改用 JS 直接 click() 目标按钮（button[type=submit]），避免坐标换算。
- **防再犯**：需要坐标点击时先确认视口（1280×960），换算后再用；按钮类交互优先 JS click()。

### 问题19：名称框选择器错误——误改文档标题（险些事故）
- **现象**：跳转 E424 时用「顶部第一个 input」定位，实际定位到 **.melo-doc-title（文档标题框）**，输入 E424+Enter 后**文档标题被改成「E424」**。
- **根因**：腾讯文档网页版顶部有文档标题框（melo-doc-title @77,15）与名称框（input.bar-label @8,150）两个 input，按 y<80 枚举会先命中标题框。
- **解决**：标题恢复为「未发布视频登记」（document.title 读取原值）；名称框 = `input.bar-label`。
- **防再犯**：名称框只认 `input.bar-label`；对文档标题框等非目标控件严禁输入/回车；发现误改立即用 document.title 原值恢复。

### 问题20：名称框跳转 JS 派发 Enter 无效 → 改用 bu 真实键盘
- **现象**：JS setter 输入 E424 + 派发 keydown/keypress/keyup Enter 后名称框显示 E424 但**选中格未跳转**（formula 区不更新）。
- **根因**：腾讯文档 WebView 对 isTrusted=false 的合成键盘事件不响应跳转。
- **解决**：`bu.click(名称框 ref) → bu.hotkey(ctrl+a) → bu.type(ref,"E{行}", submit=True)`（真实键盘）。
- **防再犯**：名称框跳转一律用 bu 真实键盘（ref 来自 snapshot 的 input.bar-label）；跳转后验证 nameBox 显示目标地址。

### 问题21：单元格编辑提交——必须用 #alloy-simple-text-editor，公式栏无效
- **现象**：在顶部公式栏（.formula-input）输入时间 + bu.press_key(Enter) / JS Enter 均**未提交**（残留文本不写入）；双击单元格坐标偏移点到 D421（进入下拉编辑态，未提交，安全）。
- **根因**：腾讯文档单元格编辑的正确编辑器是 `#alloy-simple-text-editor`（选中格后按 Enter 出现）；公式栏输入需要 F2/提交链，合成事件无效。
- **解决**（已验证有效）：
  1. 名称框跳转（bu 真实键盘）→ 验证 nameBox = E{数据行+1}；
  2. `bu.press_key("Enter")` 进入编辑态 → 确认 `#alloy-simple-text-editor` 出现；
  3. JS `focus → selectNodeContents 全选 → execCommand('insertText', false, '时间')` 输入；
  4. `bu.press_key("Enter")` 提交；
  5. JS API 回读验证目标行 E 值（±1 行对比，防止误写）。
- **防再犯**：禁止在公式栏输入时间后直接提交；禁止坐标双击定位单元格（视图滚动会偏移，09-30 实测点到 D421）；Esc 可取消编辑态，取消后需确认 formula 区清空、选中格复原。
