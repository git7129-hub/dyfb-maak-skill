## 三、今日遇到的问题与解决（规则15：阻塞问题即时沉淀）

### 问题17：商品编号输入框定位错误（查询无效）
- 现象：把编号输入到「商品名称」框（x=409,y=134）而非「商品编号」框（x=714,y=134），查询无结果。
- 根因：两个输入框同排同 y，JS 按 label 匹配失败误选第一个宽输入框。
- 解决：精确定位 x=714,y=134 输入框；查询按钮用 JS `button[type=submit]`「查询」click()。
- 防再犯：输入前校验输入框 x 坐标（商品名称≈409、商品编号≈714）；查询后回读验证列表只剩目标 ID。

### 问题18：bu.click_xy 坐标换算错误（点错按钮）
- 现象：把 JS 像素坐标（查询@338,227）直接当 click_xy 归一化坐标使用，点击落在重置按钮附近。
- 根因：click_xy 用 0-1000 归一化坐标（=像素/视口宽高×1000）。
- 解决：改用 JS click() 目标按钮，避免坐标换算。
- 防再犯：需坐标点击时先换算；按钮类交互优先 JS click()。

### 问题19：名称框选择器误选 .melo-doc-title（文档标题框），误改文档标题
- 现象：跳转 E424 时定位到文档标题框，输入 E424+Enter 后文档标题被改成「E424」。
- 根因：腾讯文档顶部有文档标题框（melo-doc-title）与名称框（input.bar-label）两个 input。
- 解决：标题恢复为「未发布视频登记」（document.title 原值）；名称框只认 input.bar-label。
- 防再犯：对非目标控件严禁输入/回车；发现误改立即用 document.title 原值恢复。

### 问题20：名称框跳转 JS 派发 Enter 无效
- 现象：JS setter 输入 E424 + 派发 Enter 后名称框显示 E424 但选中格未跳转。
- 根因：腾讯文档 WebView 对 isTrusted=false 合成键盘事件不响应。
- 解决：bu 真实键盘 `click 名称框 ref → ctrl+a → bu.type(ref,"E{行}", submit=True)`。
- 防再犯：名称框跳转一律用 bu 真实键盘；跳转后验证 nameBox 显示目标地址。

### 问题21：单元格编辑提交——必须用 #alloy-simple-text-editor，公式栏无效
- 现象：顶部公式栏（.formula-input）输入时间+Enter 均未提交；坐标双击偏移点到 D421（未提交，安全）。
- 根因：单元格编辑的正确编辑器是 #alloy-simple-text-editor（选中格后按 Enter 出现）；公式栏合成事件无效。
- 解决（已验证）：名称框跳转 → bu.press_key(Enter) 进编辑态 → 确认 #alloy-simple-text-editor → JS focus+全选+execCommand('insertText', false, '时间') → bu.press_key(Enter) 提交 → JS API 回读验证±1 行。
- 防再犯：禁止公式栏输入后直接提交；禁止坐标双击定位单元格（视图滚动偏移）；Esc 取消编辑态后确认 formula 清空、选中格复原。

### 问题22：云端环境（Cloud Linux）与 Windows 本地差异
- 现象：云端无 Windows 路径、登录态全重置。
- 解决：video_tmp 用技能目录相对路径；任务表/抖店/微盘登录重新引导；备份文件存 agent workspace。
