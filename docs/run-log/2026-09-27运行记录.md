| # | 问题 | 现象 | 解决方案 |

| 1 | SOP docx 损坏 | read.py 抛 BadZipFile（ZIP 缺中央目录，尾部全零） | 手工解析 local file headers 恢复正文+17图；以文字+已恢复截图+实际页面状态为准 |
| 2 | 视频上传失败（多次尝试） | bu.upload(ref) 报 "Node is not a file input element"；bu.upload_file 报 "no element"；点上传按钮无 file chooser | 用户指示「刷新浏览器重新试」→ 刷新后成功路径：点「单独发视频」→ 等面板载入 → **先 JS 确认页面存在隐藏 input[type=file]（accept="video/*,..."）** → 直接 upload_file 成功。经验：页面重渲染后 file input 消失，需重走面板流程；upload_file 返回 None 不代表失败，以页面状态（时长/封面/进度条）核验 |

| 6 | 时间选择器操作卡点（最难） | ① JS set value+input/change → 组件解析错乱（日期变10月8日）；② 键盘 Ctrl+A+键入+Enter → 显示 15:05:00 但组件不认（发布仍拒、输入框重置回默认）；③ 点击时间列数字（小时15）→ 有效；④ scrollTop 直接设置 → 虚拟列表渲染错乱；⑤ wheel 事件 → 不生效 | **最终方案：重新触发「定时发布」选项**（先点立即发布再点定时发布），组件重新生成「当前时间+2h+缓冲」的默认时间（15:17:15），直接发布通过。经验：该日期时间组件是受控组件，只认自己生成的状态 |

## 四、关键经验沉淀（下次直接复用）

1. **上传**：先 JS 确认 `input[type=file]` 存在 → upload_file；页面重渲染后需重走「单独发视频」面板流程。
2. **定时时间**：不要 JS 设值、不要键盘输入；直接「立即发布→定时发布」重新触发生成合法默认时间（当前+2h+缓冲）。
3. **回填**：不用 setCellDataAtPosition（不保存）；用 UI：名称框跳转 → F2 → 输入日期格式 → 回车 → 等自动保存 → 刷新验证。
4. **商品编号**：定位「商品编号」label 父行 input；查询点真 button[type=submit]。
5. **店铺切换**：主账号无切换按钮 → 需用户人工（退出登录蓝讯账号或其它方式）。
6. **挂车额度**：发布成功后才扣减；页面「今日挂车短视频可发 N 条」为唯一权威。
7. **发布成功判定**：点击发布显示「已提交发布」+ 视频管理列表出现新记录（审核通过/定时发布中）= 成功；不得只凭点击判断。
